# Smart Play
A simple Android video player (Kotlin, Jetpack Compose, Media3 ExoPlayer).

Features: video library with search, resume playback, next/previous, speed & audio-track menu,
picture-in-picture, opens videos from other apps.

## Get the APK
1. Create a GitHub repository and upload everything in this folder.
2. Open the **Actions** tab -> *Build Smart Play APK* (runs automatically on push).
3. When it finishes, download the **SmartPlay-APK** artifact (SmartPlay-release.apk).

Or locally: install Android Studio, open this folder, then Build > Build APK(s).
